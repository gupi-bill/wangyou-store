# 忘忧小卖部

> 不卖东西，也不解决问题。
> 只是在这儿放着。灯一直亮着，也没人查你为什么来。

双击 `index.html` 就能开门。不需要装任何东西，不需要联网，不需要注册，不需要登录。

---

## 货架上有什么

| | 叫什么 | 它干什么的 |
|---|---|---|
| 📻 | **深夜电台** | 六种环境音，全部由 Web Audio 的振荡器和噪声**实时算出来**。没有 mp3，没有 wav，一个字节都没下载。可以整点报时。 |
| 🌀 | **万花筒** | 算法画的曼陀罗。一个种子决定所有形状，同一个种子永远是同一张。满意了可以导出 1440×1440 的 PNG 当壁纸。 |
| 🎰 | **命运老虎机** | 写死的 **115 条**建议，抽一条让你今天做。它不智能、不联网、不看你。抽到什么就做什么。 |
| 🫠 | **拖延统计** | 诚实地记下你把时间浪费在哪儿了。不打分，不提醒，不优化。最后会告诉你那些时间本来够干什么。 |
| ✉️ | **给未来写信** | 写给以后的自己，设定日子上锁，不到日子不许拆。（改系统时间能作弊，但那就不是同一件事了。） |
| 🗄️ | **档案室** | 你的痕迹：来过的日子、低语、万花筒收藏、信。以及一本老板写的、只有你能看到的**账本**。 |

## 怎么用

```
直接用：  双击 index.html
```

如果你的浏览器在 `file://` 下不让保存数据（Safari 和旧版 Chrome 偶尔会）：

```
./start.sh          # 会起一个本地服务器并打开浏览器
```

## 它有多轻

- 零依赖。零构建。零配置。没有 `package.json`（这里不打算装任何东西）。
- 零网络请求。断网、飞行模式、拔网线，功能完全一样。
- 所有数据只写进你自己浏览器的 localStorage，前缀 `moyou:v1:`。不上传，不统计，没有 Cookie。
- 随时可以在页脚「导出存档」把全部数据带走成一个 json，或者「清空」一把抹掉。

## 暗门

店里有几个不该被找到的东西：

- 门口的输入框，不是每个词都有回应。
- 顶栏那个灯笼图标，连点七下。
- 档案室最右边那页。
- 每个应用里都藏了一句。凑齐了有奖励。
- 电台页有个"这声音是怎么来的"折叠区，六种环境音的合成原理都写在里面。
- `index.html?still=1` 可以关掉所有动画（截图、录屏、打印用）。
